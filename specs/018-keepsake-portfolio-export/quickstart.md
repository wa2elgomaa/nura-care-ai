# Quickstart: Keepsake Portfolio Export Validation

## Prerequisites
- Child media artifacts cataloged and approved
- Parent authorization and consent configured

## Scenario 1: Authorized export
1. Request export for one authorized child.
2. Verify bundle generation and download token issuance.

## Scenario 2: Cross-child privacy block
1. Attempt export with unauthorized child assets.
2. Verify hard rejection and audit record.

## Scenario 3: Revoked consent behavior
1. Revoke export consent.
2. Verify new export requests and pending tokens are blocked.
