# Research: Teacher Pattern Insights

## Decision: Rules-only Phase 3 flagging
- Decision: Use deterministic thresholds and plain-language templates; no ML classifiers.
- Rationale: aligns with constitution and explainability-first mandate.
- Alternatives considered: predictive model scoring (rejected).

## Decision: Staff-only segregation
- Decision: isolate insights to staff/director interfaces and block parent notifications.
- Rationale: prevents misinterpretation and policy violations.
- Alternatives considered: optional parent digest (rejected).

## Decision: Clinical threshold governance
- Decision: require advisor review workflow before rule activation.
- Rationale: improves safety and language appropriateness.
- Alternatives considered: product-only threshold tuning (rejected).
