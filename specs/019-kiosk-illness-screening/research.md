# Research: Kiosk Illness Screening

## Decision: Deterministic screening rules
- Decision: use threshold/checklist rule matrix and rationale codes.
- Rationale: aligns with non-diagnostic requirement and explainability.
- Alternatives considered: predictive illness model (rejected).

## Decision: Operational outcomes only
- Decision: output staff action guidance, never diagnosis statements.
- Rationale: preserves medical-device boundary.
- Alternatives considered: condition-specific risk wording (rejected).

## Decision: Consent-first kiosk workflow
- Decision: enforce consent check before automated capture; provide manual fallback.
- Rationale: lawful handling and continuity under missing consent.
- Alternatives considered: implicit consent assumptions (rejected).
